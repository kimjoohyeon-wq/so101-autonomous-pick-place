# Codex for OSS 신청서 초안

## 프로젝트 정보

**프로젝트명:** SO-101 Autonomous Pick-and-Place with Hybrid AI Vision Pipeline

**설명:** SO-101 로봇 팔을 위한 AI 비전 기반 자율 pick-and-place 시스템. Classical CV와 Vision-Language Model을 결합한 하이브리드 검출기를 통해 제조 현장의 무인 자동화를 목표로 하는 오픈소스 프로젝트입니다.

**라이선스:** MIT (예정)

---

## 1. 프로젝트가 중요한 이유

### 제조업 자동화의 현실적 문제 해결
- 국내 중소 제조업체의 가장 큰 과제는 **엔지니어 부족**입니다. 사람이 24시간 감시할 수 없는 로봇 작업에서 AI 기반 자율 판단이 필수적입니다.
- 본 프로젝트는 **"퇴근 후 무인 운전"**을 실제로 구현합니다. CV 게이트가 0.01초로 실시간 감시하고, 이상 발생 시에만 VLM이 복구 계획을 생성합니다.

### 새로운 접근법: CV Gate + VLM Cascade
- 대부분의 로봇 비전은 "전부 AI" 또는 "전부 classical CV" 중 하나를 선택합니다.
- 본 프로젝트는 **두 방식의 장점만 결합**했습니다:
  - CV로 자신 있는 케이스는 즉시 처리 (92.9% 커버, 0.01초)
  - 모호한 케이스만 VLM/GPT에 위임 (7.1%, API 비용 최소화)
- 이 패턴은 NVIDIA LiteVLM(2025) 같은 최신 연구와 같은 철학을 공유하며, **재현 가능한 구현체**를 오픈소스로 제공합니다.

## 2. 생태계 영향력

### 로봇 플랫폼 의존성
- SO-101 로봇 팔은 교육·연구용으로 전 세계 대학/연구소에서 사용됩니다.
- LeRobot, OpenManipulator 등 주요 오픈소스 로봇 프레임워크와 호환됩니다.
- 본 프로젝트의 파이프라인은 **SO-101에 국한되지 않고** 모든 USB 카메라+로봇 팔 조합에 적용 가능합니다.

### 다운스트림 영향
- **제조업 SME**: 엔지니어 없이도 AI 비전 기반 자동화 도입 가능
- **로봇 교육**: CV+AI 하이브리드 학습을 위한 실전 예제
- **연구 커뮤니티**: 재현 가능한 CV+VLM cascade 벤치마크

### 기술적 기여
| 구성요소 | 기여 내용 |
|---------|----------|
| CV 게이트 | HSV 블롭 기반 초고속 검출 (100% 정확도) |
| Qwen2-VL 통합 | 로컬 GPU에서 VLM 추론 (RTX 3080 10GB) |
| 자율 복구 루프 | 상태 머신 + VLM 복구 계획 생성 |
| Codex 통합 | GPT-5 vision으로 공간 추론 기반 grasp planning |

## 3. 보안 민감도

### Physical Safety Critical
- 로봇 팔의 오작동은 **사람 부상**으로 이어질 수 있습니다.
- 본 프로젝트의 CV 게이트는 AI 모델보다 **결정론적이고 검증 가능한** 안전장치를 제공합니다.
- Codex Security의 자동 취약점 검증은 로봇 제어 코드의 안전성을 높이는 데 직접 기여합니다.

### 공급망 보안
- 오픈소스 로봇 제어 코드는 제조 현장에서 직접 실행됩니다.
- 의존성 체인: Python, OpenCV, PyTorch, transformers, requests → 광범위한 공급망
- Codex Security를 통한 정기적 취약점 스캔이 필요합니다.
